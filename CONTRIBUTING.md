# Contributing to What-If Machine

What-If Machine is proprietary, source-available software owned by Matthew
Newland. It is not an open-source project.

## Bug reports are welcome

You may open an issue to report a bug or reproducible failure. For a
model-driven issue, include only information you are authorized to share:

- the model tag and Ollama version;
- the command that was run;
- the smallest workspace that reproduces the problem;
- the relevant, redacted run-log excerpt; and
- the expected and observed behavior.

Never post credentials, private prompts, personal data, wallet information, or
other secrets.

## Code and documentation contributions

Do not submit source-code, documentation, artwork, or other content changes
unless Matthew Newland has approved the contribution in writing before it is
submitted.

Any accepted contribution must be covered by a separate written agreement that
addresses copyright ownership and licensing. Opening a pull request by itself
does not transfer copyright and does not guarantee that the contribution will
be reviewed, accepted, or merged.
